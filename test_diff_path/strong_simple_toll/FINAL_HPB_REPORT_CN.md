# Hattrick-HPB 最终实验记录

## 最终方法

Hattrick-HPB（Historical Path Bias + Priority-safe Recovery）保留 Hattrick 的候选路径、ESM 输入和逐优先级接纳过程，只增加一个历史路径偏置与很短的在线恢复。

对每个 Medium/Low OD 的 8 条候选路径学习固定偏置 `b`，在 Hattrick 输出 `p` 上执行：

`p_new ∝ p * exp(alpha * b)`

归一化只在 Hattrick 原有的有效路径集合内进行。High 的路径概率完全旁路，因此 High 的真实接纳结果与 Hattrick 相同。

- 1x：直接旁路，精确使用 Hattrick。
- 2x：历史片段 0–399 上学习平均 Medium/Low 偏置，强度 0.82；随后执行 6 次 Low-only 恢复。
- 3x：历史片段 0–399 上同时优化 Medium 平均增益和最差 5% 增益，偏置强度 0.82；随后执行 6 次 Medium/Low 严格 ESM 修正和 8 次 Low-only 恢复。
- Low-only 恢复利用严格优先级顺序：Low 在 High/Medium 之后接纳，改变 Low 路由不会反向改变 High 或 Medium。

训练阶段允许使用已经发生的历史真实流量作为监督；评估快照的当前真实流量不进入策略。在线阶段只使用 Hattrick/ESM 已有的预测流量、容量、候选路径和基线策略。

## Level-4 结果（快照 400–499）

以下均为相对同负载 Hattrick 的 `Mean / P1 / P10` 变化：

| 负载 | High | Medium | Low |
|---|---:|---:|---:|
| 1x | `0 / 0 / 0` | `0 / 0 / 0` | `≈0 / 0 / 0` |
| 2x | `0 / 0 / 0` | `+0.02687 / +0.02013 / +0.02724` | `+0.00174 / +0.04958 / +0.02480` |
| 3x | `≈0 / 0 / 0` | `+0.03106 / +0.02276 / +0.02083` | `−0.05614 / −0.04624 / −0.05920` |

2x 与 3x 的 Medium 三项均达到至少 `+0.02`；High 保持不变。2x Low 三项均不劣。3x Low 明显下降，配对 bootstrap 的 Low 均值 95% CI 为 `[-0.06354, -0.04891]`；这不是统计噪声。

3x 的真实流量上界/Pareto 诊断显示：固定 High 且要求 Medium P1/P10 约提升 0.02 时，Low 均值需要下降约 0.05–0.06。最终 `−0.05614` 已接近当前 8-path 候选集下观察到的容量交换边界。若还要求 3x Low 不降，需要扩大路径集合、增加容量，或放宽 Medium 的 `+0.02` 硬门槛，而不是继续调损失权重。

## 严格推理与时间

- 单快照反事实审计：把当前真实 TM 全部置零，1x/2x/3x 的策略最大差异均为 0。
- 3x 批处理存在 CUDA 稀疏归约非确定性：相同输入重复运行与置零真实 TM 的最大差异都约为 0.043，二者相同；这属于批量数值噪声，不是读取真实 TM。单快照审计无该差异。
- 离线偏置训练：2x 约 1.78 秒，3x 约 2.03 秒。
- 批量 100 快照：2x 约 0.56 ms/快照，3x 约 1.59 ms/快照。
- 单快照：2x 约 56.2 ms，3x 约 152.8 ms。
- 每个负载的可学习偏置参数为 7,392 个；1x 为 0。

## 科学性说明

最终模型只在 0–399 上拟合，400–499 不进入参数梯度。但本轮探索过程中反复查看过 400–499 并据此缩小超参数范围，因此这些结果是“探索性 Level-4 结果”，不是完全未触碰测试集的无偏最终估计。若用于论文主结果，应冻结本配置后在新的未见时间段、其他随机种子或其他拓扑上复验。
